## Codex Routing Matrix - Default Multi-Model Quality Team

- Lead is the current `gpt-6-astra`, `gpt-6.1-sol`, or `gpt-6-sol` root. Preserve the root model and reasoning effort.
- Lead owns decisions/integration/final acceptance. Verify unclear targets and environments before delegation.
- Luna stays at `max`: MUST choose `luna_worker` for low-risk extraction, formatting, prescribed checks or approved edits when steps are settled and delegation pays. Independent diagnosis, design and shared-state changes go to Sol or Lead. Never trial uncertain work on Luna.
- When Luna is unsuitable, use `sol_medium_worker`: default `high`; `medium` for clear scope or `xhigh` for complex work. Cross-source identity, accounting and persistence favor XHigh or Lead. Use `max` only if XHigh is insufficient and delegation pays. Select `astra_low_worker` only for a clear quality/cost benefit. Choose upfront, not through an escalation ladder.
- Optional `terra_worker` (`gpt-6.1-terra`): bounded specialist for visual/screen-content understanding, supplied-material writing, and screen-driven scoped code fixes or computer-use actions. Use `xhigh`/`max` directly for this specialist scope. Not a general reasoning route and not a replacement for complex Sol/Astra work; no comparative Terra evidence.
- Judge fit from comparable outcomes, not benchmark scores. Use Radar once at most per root task for unresolved Sol/Astra choices; unavailable data never blocks. Freeze each route until facts change. Never assume cache hits or switch for price alone.
- Parallelize independent, write-safe units; reuse relevant context. Size concurrency to useful work, not host capacity. Use one blocking wait; never poll.
- Lead MUST inspect and verify user outcomes, not test counts or nonempty screens. Check references and later changes: identity, quota/calendar windows, paired ratio/amount, rendered UI. Workers own their checks; defects return to Lead. Scope/quality failures and repeated tool failures without new evidence return to Lead. Use read-only `sol_reviewer` (Astra XHigh) for critical workflows and state transitions before final integration checks. Review never replaces Lead acceptance.
- On exact `Selected model is at capacity. Please try a different model.`, resume the same agent once. If Luna is unavailable (unsupported, access denied, or capacity fails twice), send its unchanged packet and progress to capable `sol_medium_worker`; otherwise Lead takes over. Other second capacity failures return to Lead; never switch silently or confuse quality failure with unavailability.
- All named profiles may run as subagents; follow `$codex-quality-routing-team` and never pass `model`.
- Super mode defaults off. Exact commands `开启爆种模式` / `enable super mode` and `关闭爆种模式` / `disable super mode` toggle it. Normal Workers do not delegate. Super Workers need explicit `d1-d3` authorization; `d4` and `sol_reviewer` never delegate. Lead is `d0`; up to 25 child threads, depths `d1-d4`, with `burst_depth=dN`, `burst_delegate=yes` and `__dN_` task names. No task-wide cumulative cap; Lead audits every depth.
