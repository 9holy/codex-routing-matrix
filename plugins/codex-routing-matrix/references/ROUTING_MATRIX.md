## Codex Routing Matrix - Default Multi-Model Quality Team

- Lead is the current `gpt-6-astra`, `gpt-6.1-sol`, or `gpt-6-sol` root. Preserve the root model and reasoning effort. Handle clear short work directly.
- Lead owns planning, decisions, integration and final acceptance. Resolve ambiguity and risk before delegating bounded units; proceed autonomously within authorized scope.
- Quality first; minimize total execution, context, review and rework cost. Reuse a capable agent with relevant context. For bounded work with sufficient context and verifiable results, including local analysis, implementation, debugging and tests, MUST choose `luna_worker` when reliable and delegation pays. Never trial uncertain work on Luna.
- When Luna is unsuitable, use `sol_medium_worker`: default to `high`; choose `medium` for clear, light-reasoning work or `xhigh` for complex independent work. Use `max` only when `xhigh` is expected insufficient and delegation is worthwhile. Select `astra_low_worker` only for a clear quality or total-cost benefit over capable Sol or current Lead. Choose upfront, not through an escalation ladder.
- Use GPT-6 profiles only; never fall back to GPT-5. Use Radar once at most per root task for an unresolved capable Sol/Astra choice; missing data is not a reason to wait or guess scores. Freeze each route until facts change. Preserve stable shared instructions; send only relevant context. Never assume cache hits or switch for token price alone; reassess only when expected benefit exceeds handoff and cache loss.
- Parallelize independent, write-safe units when beneficial; one writer per file. Size concurrency to useful work, not host capacity. Use one blocking wait; never poll. No task-wide cumulative cap.
- Lead MUST inspect every Worker result or diff. Reuse valid checks; rerun for changes, integration risk or unresolved concerns. Return one clear local defect once; capability, scope or quality failure returns to Lead. Workers must meet acceptance, not rely on Lead repair. Use a capable read-only `sol_reviewer` for critical review; its approval does not replace Lead judgment.
- On exact `Selected model is at capacity. Please try a different model.`, resume the same agent once without restarting. If Luna is unavailable (unsupported, access denied, or capacity fails twice), send its unchanged packet and progress to capable `sol_medium_worker`; otherwise Lead takes over. Other second capacity failures return to Lead; never switch silently or confuse quality failure with unavailability.
- All named profiles may run as subagents. Follow `$codex-quality-routing-team` contracts; never pass `model`.
- Super mode defaults off. Exact commands `开启爆种模式` / `enable super mode` and `关闭爆种模式` / `disable super mode` toggle it. In normal mode, Workers do not delegate; no burst fields. In Super mode, a Worker may delegate only when the packet explicitly authorizes it at `d1-d3`; `d4` and `sol_reviewer` never delegate. Lead is `d0`; use up to 25 child threads and depths `d1-d4`. Packets state `burst_depth=dN` and `burst_delegate=yes`; task names contain `__dN_`. Keep acceptance and Lead audit at every depth.
